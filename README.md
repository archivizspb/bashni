# Башни «Ленсити»

Рабочая 3D-модель двух закрученных башен для конкурса «Взгляд в будущее» (Кудрово), вариант 23.10.2026.

Страница: https://archivizspb.github.io/bashni/

- ползунки высот, закрутки и ширины разрыва, высоты этажа, плана, короны и общего этажа — форма перестраивается в браузере;
- профиль по высоте: ширина внизу, наверху и расширение в точке на заданной высоте (точку можно тянуть на графике);
- общая библиотека вариантов с превью: сохранённые варианты видят все, список обновляется сам; удалить может автор (и владелец по ключу, страница с #admin); без связи с сервером варианты сохраняются в браузере;
- виды «Аксонометрия», «Сверху», «Снизу», «Юг», «Восток», «Север», «Запад» — параллельная проекция, «3D свободно» — перспектива.

`geom.js` — генератор формы (тот же, что встроен в `index.html`), перенос компонента «Башни» из Grasshopper.

`server/` — сервис общей библиотеки (Python, только stdlib) за Caddy на VPS: https://64-188-62-43.sslip.io:8443/api/variants.
